# listinha

Lista de compras e gastos compartilhados em grupo.

Um grupo (ex.: as pessoas de uma casa) registra o que está faltando, como papel higiênico, amaciante ou arroz. Quem estiver no mercado sabe exatamente o que comprar e, depois da compra, registra quanto custou cada item, seja ele pendente ou não.

Projeto desenvolvido na [Trilha de Evolução Técnica](https://github.com/vinicimdohs/trilha-tecnica), evoluindo no ritmo dos níveis.

## Objetivos do MVP

1. **Saber o que comprar:** quem estiver no mercado tem uma visão clara do que falta em casa.
2. **Controlar gastos:** saber com certeza quanto se gasta com cada item.
3. **Duração dos produtos:** ter noção de quanto tempo dura cada produto comprado.
4. **Comparar preços:** acompanhar se um produto está ficando mais barato ou mais caro.

## Ideias para depois do MVP

- Grupos de uso geral (ex.: churrasco entre amigos), com convite de participantes.
- Divisão automática de despesas: quanto cada participante deve ao outro.

## Stack

Go, usando a biblioteca padrão sempre que possível.

> Em construção. Requer [Go](https://go.dev/dl/) 1.27 ou superior.
